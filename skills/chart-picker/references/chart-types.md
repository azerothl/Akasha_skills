# Chart type decision tree

- **Compare categories** → bar (vertical) or horizontal bar if long labels
- **Trend over time** → line (single series) or area (emphasize volume)
- **Part of whole** → pie/donut only if ≤6 slices; else stacked bar
- **Correlation** → scatter (+ trend line if linear)
- **Distribution** → histogram or box plot
- **Geographic** → choropleth map (if geo data)
- **Many dimensions** → heatmap or parallel coordinates (advanced)

Always label axes and include units.
