# Framework Report

Short **strategy report** (2 phases): pick framework → write report.

## Phases

1. **Framework** — MECE issue tree, SWOT, or Porter's five forces (user choice or infer)
2. **Report** — Executive summary, analysis, recommendations (max ~1500 words unless user asks more)

## Data authenticity

Mark inferred vs sourced data. Use **web_search** for market facts when needed.

## Provenance

Inspired by deer-flow consulting-analysis; shortened for Akasha.
