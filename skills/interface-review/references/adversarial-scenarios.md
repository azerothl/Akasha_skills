# Adversarial UX scenarios

Run mentally or via browser when available:

1. **Spam click** — double-submit forms, rapid nav clicks
2. **Empty data** — zero rows, empty search results, first-time user
3. **Extreme content** — 500-char title, RTL text, emoji-only input
4. **Slow network** — loading skeletons vs frozen UI (inspect code for pending states)
5. **Keyboard only** — Tab through entire flow without mouse
6. **Zoom 200%** — layout still usable (code review: flex/grid overflow)
7. **Wrong password 5x** — lockout/rate-limit messaging present?

Record failures with severity P0–P3.
