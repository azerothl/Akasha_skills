# Query patterns (Web Researcher)

Use these as templates; replace `{topic}`, `{entity}`, `{year}`.

## Temporal freshness

- `{topic} {year} latest`
- `{topic} announcement {year}`
- `site:github.com {topic} releases`

## Authority targeting

- `{topic} site:docs.{vendor}.com`
- `{topic} official documentation`
- `{entity} annual report OR 10-K`

## Comparison

- `{topic A} vs {topic B} comparison`
- `{topic} alternatives pros cons`

## Validation / fact-check

- `"{exact claim}" fact check`
- `{topic} debunk OR myth`

## OSINT-light (public only)

- `{domain} WHOIS` (via search results, not illegal scraping)
- `{company} SEC filing`
- `{project} github issues security`
